# Сайт канала kmcaq

Статический сайт для GitHub Pages. Главная, игровая полка, ссылки и обратная связь.

## Файлы

- `css/site.css` — общая тема, контейнер, шапка и подвал.
- `css/home.css`, `games.css`, `links.css`, `feedback.css` — оформление страниц.
- `css/admin.css` — оформление редактора игровой полки.
- `js/game-data.js` — проверка данных, допустимых ссылок и сочетаний статуса с тиром.
- `js/gameshelf.js` — карточки и окно подробностей; общий конструктор используется админкой.
- `admin.js` — вход через существующий Worker, редактирование и сохранение.
- `data/games.json` — игры. Имена должны быть уникальными без учёта регистра.

Верхний ряд главной называется «Игры на канале»: сначала текущие игры, затем все завершённые в порядке данных. Даты прохождения не предполагаются. Игровая полка показывает все игры и может расти по высоте. В редакторе можно выбрать ручное или автоматическое назначение тира; перетаскивание в «Играю сейчас» или «В планах» согласует статус с разделом.

`hero-bg.webp`, `avatar.webp` и `favicon.png` получены из исходных PNG без перерисовки. Исходники сохранены.

## Проверка и запуск

Для тестов нужен Node.js 18 или новее:

```sh
npm ci
npm test
```

Тесты проверяют сохранность записей при отклонённых изменениях, ручные тиры, создание карточек на пустой полке, безопасный вывод данных, статусы, сохранение и ошибки запросов. Внешние API в тестах заменены заглушками; реальные сообщения и изменения данных не отправляются.

Для локального просмотра:

```sh
python3 -m http.server 8000
```

Сайт не требует сборки. При изменении CSS или JavaScript обновляйте параметр `v` у соответствующих подключений на всех затронутых страницах. Серверный код Cloudflare Workers находится вне этого репозитория.
